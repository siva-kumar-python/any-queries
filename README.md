# ❓ Any Queries?

A lightweight static web project — a **query/FAQ-style landing page** built with pure HTML and CSS. Users can browse questions and answers without any backend.

## 📄 Files

| File | Purpose |
|---|---|
| `index.html` | Main landing page |
| `any_queries.html` | Queries view |
| `any.png` / `any_with_text.png` | Preview screenshots |

## 🚀 Run It

Static site — just open `index.html` in your browser:

```bash
git clone https://github.com/siva-kumar-python/any-queries.git
cd any-queries
# open index.html in your browser, or:
python -m http.server 8000
```
